# Расширение Chrome «Админка»

Расширение для Google Chrome, которое входит в админку по почте
и паролю и перекрашивает карту прямо в игре по силе игроков — так же, как
режим «Сила» на карте партии в админке.

## Установка

В магазине Chrome расширения нет, ставится оно из папки:

1. Скачайте папку `extension` целиком.
2. Откройте в Chrome адрес `chrome://extensions`.
3. Справа вверху включите **«Режим разработчика»**.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку
   `extension`.
5. Закрепите значок: кнопка-пазл справа от адресной строки → булавка
   у «Админки».

Chrome иногда напоминает, что расширение установлено не из магазина, — это
нормально для такой установки.

**Обновление.** Замените файлы в папке новыми, на `chrome://extensions`
нажмите у «Админки» стрелку-обновление и перезагрузите вкладку с игрой:
уже открытая вкладка продолжает работать со старой версией.

## Вход

1. Нажмите на значок «Админки».
2. Впишите адрес админки (например, `https://admin.example.com`), свою почту
   и пароль — те же, что на сайте.
3. Chrome спросит, можно ли расширению обращаться к этому адресу. Разрешите:
   без этого оно не достучится до админки.

Адрес нужен с `https://`. По голому `http` пароль уходил бы открытым
текстом, поэтому такой адрес расширение не примет. Исключение —
`http://localhost` и `http://127.0.0.1` для проверки на своём компьютере.

После входа расширение помнит его 30 дней с последнего использования.
Пароль оно не хранит — только выданный сервером токен.

## Раскраска карты в игре

Доступна не всем аккаунтам. Если вашему она закрыта, в игре после нажатия
кнопки появится «Раскраска карты по силе вашему аккаунту недоступна».

1. Войдите в расширении (см. выше).
2. Откройте партию на supremacy1914.com и дождитесь, пока загрузится карта.
3. Внизу слева появится кнопка **«⚔ Сила»** — нажмите её.

Страны на политической карте перекрасятся по тому, насколько их игрок
сильнее или слабее вас:

| цвет | кто это |
|---|---|
| красный | намного опаснее вас |
| оранжевый | опаснее |
| жёлтый | примерно поровну |
| зелёный | слабее |
| синий | намного слабее |
| светло-серый | счёта нет — сайт про игрока ничего не сказал |
| тёмно-серый | компьютер |
| малиновый | вы |

Пока раскраска включена, страны заливаются чистым цветом, как в легенде,
и туман войны их не белит: страны, которых вы не видите, красятся так же.
Границы стран остаются. Если карта была в режиме отношений (дипломатии),
на время раскраски она переходит в политический — в режиме отношений игра
красит страны по отношению к вам, а не цветом страны. Выключение
возвращает карту как была.

Под кнопкой — легенда: сколько игроков в каждой полосе, и ваш уровень,
кд и сила. Сила — уровень, умноженный на кд; полоса — во сколько раз
сила игрока больше вашей (≥ 1.5 — намного опаснее, ≥ 1.15 — опаснее,
≥ 0.85 — поровну, ≥ 0.5 — слабее, меньше — намного слабее).

- Сравнивается с тем аккаунтом, которым вы играете в этой вкладке, а не
  с игровым ID из профиля админки.
- Если у вас самих счёта ещё нет, сравнивать не с чем — карта будет серой.
- Первое включение в большой партии может занять до минуты: админка
  дособирает счёт игроков, которых давно не видела. Дальше — быстро.
- Пока раскраска включена, состав перечитывается раз в 10 минут: в партию
  приходят новые игроки, места выбывших занимают боты.
- Повторное нажатие возвращает родные цвета. Расширение помнит, включена ли
  раскраска, и в следующей партии включит её само.
- Раскраска видна только вам, в вашем браузере. В игру ничего не
  отправляется, другие игроки ничего не замечают.

Если игра обновит свой клиент, раскраска может перестать работать —
тогда под кнопкой появится «Клиент игры не дал перекрасить карту».

## Когда вход обрывается

Расширение попросит войти снова, если:

- вы нажали «Выйти» в расширении;
- в профиле админки нажали **«Отключить расширение»**;
- сменили пароль, изменили роль или закрыли доступ в «Доступах»;
- расширением не пользовались 30 дней.

Узнать, подключено ли расширение, и отключить его на всех устройствах
разом можно в профиле админки, блок «Расширение Chrome». Входы из
расширения видны руту в «Входах» с пометкой «расширение».

## Для разработчиков

Файлы (Manifest V3, сборки нет — папка грузится в Chrome как есть):

| файл | где работает | что делает |
|---|---|---|
| `manifest.json` | — | описание расширения |
| `popup.html`, `popup.css`, `popup.js` | окно значка | вход и выход |
| `background.js` | фон (service worker) | единственный, кто ходит на `/api/power`; токен знает только он и окно |
| `game-content.js` | страница игры, изолированный мир | кнопка «⚔ Сила» и легенда в закрытой тени, связь фона с `game-main.js` |
| `game-main.js` | страница игры, мир клиента (`MAIN`) | читает состав партии и перекрашивает карту |

Доступ к серверу — через `optional_host_permissions`: адрес админки
задаёт человек, и разрешение на него спрашивается при входе. Постоянных
прав на все сайты у расширения нет. Скрипты игры подключаются только на
`https://(www.)supremacy1914.com/clients/*`, во всех фреймах: клиент игры
живёт во фрейме.

### Как перекрашивается карта

Карта в клиенте — three.js; провинцию он заливает цветом владельца,
`players[owner].getPrimaryColor()`, в виде `rgba(r,g,b,255)`, и пересчитывает
цвета по событию обновления игроков.

1. `game-content.js` ждёт, пока `hup.isGameLoaded()`, и только тогда
   показывает кнопку.
2. По нажатию просит у `game-main.js` состав (postMessage, канал
   `admin-power`): из `hup.gameState.getPlayerState().getPlayers()` —
   номер в партии, номер на сайте, бот ли; свой — из `hup.config.userData`.
3. Номера на сайте людей уходят фону, фон — на `POST /api/power`.
4. `game-content.js` раскладывает ответ по полосам и отдаёт цвета
   `game-main.js`.
5. `game-main.js` один раз подменяет `getPrimaryColor` на общем прототипе
   профилей (новые профили наследуют подмену) и зовёт
   `PlayerState.publishUpdate()` — карта перерисовывается сама.
   Выключение — сброс цветов и то же обновление.

Сам клиент цвет страны бледнит, и в два прохода:

- провинции рисуются в отдельную текстуру: цвет разбавлен (`c·0.7 + 0.3`),
  шейдер добавляет `+0.3` белого и затемняет рельефом и светом. Альфа этой
  текстуры — данные (бит «выделена» и маска суши), её не трогаем;
- плоскость карты собирает кадр вместе с текстурой тумана: невидимое белит
  на 80% и притеняет (`uFowIntensity`). В той же текстуре — границы стран.

`game-main.js` вписывает переключатель `uAdminPaint` в оба шейдера
(`mapRenderer.provinces.material` и `mapRenderer.planeMaterial`, где
`mapRenderer` — `hup.ui.mapWidget.mapRenderer`). Пока он 1, суша берёт наш
цвет почти плоским, а туман не белит и не притеняет; границы остаются.
Шейдер, устроенный не так, как ждём, остаётся родным.

Токен и сеть в мир клиента игры не попадают: `game-main.js` видит только
готовые цвета. Если клиент обновят и что-то внутри переименуют,
`game-main.js` отвечает ошибкой, а не падает молча.

### API сервера

Все ответы — JSON, ошибка — `{"error": "текст для показа"}`.

| запрос | что делает |
|---|---|
| `POST /api/auth/login` `{"email", "password"}` | вход; ответ `{"token", "expires_at", "user"}` |
| `GET /api/auth/me` | кто владелец токена; `401`, если токен погашен |
| `POST /api/auth/logout` | погасить токен; `204` |
| `POST /api/power` `{"me", "players"}` | сила игроков относительно `me`; см. ниже |

Токен шлётся заголовком `Authorization: Bearer <токен>`.

`/api/power` принимает номера на сайте (`siteUserID`) строками: `me` — тот,
кто играет во вкладке, `players` — люди партии, до 1000, только цифры.
Тело — до 64 КБ. Ответ:

```json
{
  "me": {"power": "", "rated": true, "level": 42, "kd": 1.31, "danger": 55.02},
  "players": {
    "123456": {"power": "power-up", "rated": true, "level": 51, "kd": 1.2, "danger": 61.2}
  }
}
```

`power` — `power-much-up`, `power-up`, `power-even`, `power-down`,
`power-much-down` или пусто, если счёта нет у игрока или у самого `me`.
Открыто ультра-пакету (`domain.Plan.CanPaintGameMap`), остальным — `403`;
кривой состав — `400`. Сервер в партию не ходит: счёт берётся из базы,
а устаревший (старше недели) дособирается у сайта тем же `freshStats`, что
и карта партии в админке, — ждём не дольше минуты.

Как устроено на сервере:

- токен — строка в `sessions` с `kind = 'extension'` (миграция 00033):
  блокировка, смена пароля и роли гасят его вместе с браузерными сессиями;
- в базе лежит только хеш токена, срок — 30 дней, продлевается при
  использовании (`auth.ExtensionTTL`);
- токен расширения не принимается как кука сайта, а кука — как токен;
- `/api/` идёт мимо проверки происхождения и CSRF: обе защищают куку,
  а API куки не читает. Вход принимает только `application/json`, поэтому
  чужая страница не может отправить его даже вслепую;
- входы пишутся в `login_events` с `via = 'extension'`.

Код — `internal/web/api.go`, `internal/auth/session.go`
(`LoginExtension`, `CurrentExtension`), тесты — `internal/web/api_test.go`.
